# 图布局 x 坐标选择：问题与较优算法

## 问题

给定图 G=(V,E)、每个节点 i 的固定 y 坐标 y_i。为每个节点选 x 坐标，要求：

- x 是 {1,…,n} 的排列（任意两节点 x 不同——与 y 唯一性合起来即「任意行列不共用」）；
- 最小化欧氏总边长 Σ_{(i,j)∈E} √((x_i − x_j)² + (y_i − y_j)²)。

本项目触发点：F-5 时间轴（y = 成书年序数）定了之后，x 怎么排才能让边总长最短，就是这个问题。

**本项目边集 E 只含继承边**（QA 2026-10-16 A19/A20）：反驳边是跨体系张力线，画出来但不参与定位——若计入，被反驳的两端会被拉近，视觉上误导为同一体系。反驳边要「可见但不影响布局」。

## 这是不是已知问题

是。属于图绘制 / 图布局领域的**x-coordinate assignment problem**（Sugiyama 框架第三阶段）。

| 相关问题 | 目标 | 复杂度 |
|---|---|---|
| **MinLA**（最小线性排列） | min Σ \|π_i − π_j\| | 一般图 NP-hard（Garey–Johnson 1976），树上多项式（Chung 1984） |
| **二次版本** | min Σ (π_i − π_j)² | 连续松弛即谱布局（Hall 1970），Fiedler 向量 |
| **本问题**（带 y 偏移的欧氏版） | min Σ √((π_i − π_j)² + c_{ij}) | NP-hard；连续松弛**凸**，可解 |

工程实现里 **Brandes–Köpf (2001)**（线性时间启发式）和 Graphviz dot（二次规划）是常见参考。

## 推荐方案：连续松弛 + 排名投影 + 2-opt

精确解 NP-hard，但较优解很好拿。三步法：

### 第 1 步：解连续松弛（凸）

令 c_{ij} = (y_i − y_j)²。目标

$$\min_{x\in\mathbb{R}^n} \sum_{(i,j)\in E} \sqrt{(x_i − x_j)^2 + c_{ij}}$$

每项是凸函数，和仍凸。**IRLS（迭代重加权最小二乘）**几次迭代收敛：

```
x ← 初值（谱向量或随机）
重复 10–30 次：
    w_{ij} ← 1 / √((x_i − x_j)² + c_{ij} + ε)       # ε≈1e-6 防除零
    解带权 Laplacian 系统 L_w x = 0
    附归一化约束 Σx_i = n(n+1)/2, Var(x) = n²/12   # 防塌缩到常数
```

每轮一个稀疏线性方程组，n < 1000 几百毫秒。得到的 x 是**连续全局最优**，也给出离散最优的下界——用来评估步 2/3 的 gap。

### 第 2 步：排名投影

把连续 x 从小到大排序，重标 1…n（argsort 的秩）。

### 第 3 步：2-opt 局部搜索

```
重复：
    对每对 (i, j)：
        Δ ← 交换 π_i ↔ π_j 后的总边长变化
        若 Δ < 0：交换
直到一整轮无改进
```

Δ 只涉及 i、j 的邻居边，单次 O(deg(i)+deg(j))。

## 可选增强

| 选项 | 何时加 | 期望收益 |
|---|---|---|
| 多随机起点跑步 1，取最优 | n > 50 且图结构复杂 | 5–15% |
| 2-opt 换**模拟退火** | 局部最优仍离下界远 | 3–8% |
| **整数规划**精确求解 | n ≤ 15 | 全局最优 |
| **Brandes–Köpf** 替代步 1–2 | 想要线性时间、对总长要求不高 | 速度，不是质量 |

## 复杂度与规模边界

| n | 时间（三步法总计） | 典型 gap vs 连续下界 |
|---|---|---|
| ≤ 50 | 秒级 | 1–3% |
| ≤ 500 | 几秒 | 2–5% |
| ≤ 5000 | 几十秒 | 5–10%（可加随机起点压低） |
| 更大 | 稀疏图线性系统求解器（CG + Jacobi 预处理）仍可做；2-opt 换邻域扫描 | 工程层事情 |

## 实现要点

- **Laplacian 系统带归一化**：直接解 Lx = 0 得全零解。固定 x_1 = 0、x_n = n−1 或加均值/方差约束。Python 用 `scipy.sparse.linalg.spsolve` + 增广矩阵。
- **ε 不要太小**：ε 过小 IRLS 后期震荡；1e-4 到 1e-6 之间都行。
- **收敛判据**：目标函数变化 < 1e-6 或迭代 30 次封顶。
- **非连通图**：按连通分量分别布局，再在 x 轴串接（分量间无边不影响目标）。
- **带权图**：边乘权 w_{ij}，IRLS 的 w 换成 w_{ij}/√(...)。

## 适用边界

- 本问题要求 x 是**排列**（整数且两两不同）。如果允许任意实数、仅要求两两不同，第 1 步的连续解加个最小间隔扰动就够了，不需要步 2/3。
- 如果边有「不能交叉」约束（如 Sugiyama 的分层限制），这里给出的算法不保证——需换用 Brandes–Köpf 这类专门处理交叉的方法。
- 如果目标不是总边长而是**最大边长**（bandwidth minimization），是另一个问题，另选算法。
