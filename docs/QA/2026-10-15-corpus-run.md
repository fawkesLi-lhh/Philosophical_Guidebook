3. **Begriffsschrift 定位法**：GitHub API 搜书名原词（而非英文描述词）直接命中电子化仓库——德文/原语言书名做查询词比英文泛词有效得多。

搜索方法论结论：bing 中文词几乎无效；英文书名精确短语次之；最有效是「已知站名 + 作者/书名原语言词」定向搜，以及 GitHub API 用书名原词搜。
